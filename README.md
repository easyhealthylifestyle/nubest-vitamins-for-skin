# Skin Vitamins, Food First

A one-page guide to five vitamins linked to healthy-looking skin: **vitamins C, E, A, D and B3**. It shows which everyday foods provide each one, how much adults need, where the safe upper limits sit, and what to check before adding a supplement.

**Live site:** https://easyhealthylifestyle.github.io/nubest-vitamins-for-skin/

Companion to NuBest’s article [Top 5 Best Vitamins for Skin Glow](https://www.nubest.com/blogs/beauty-care/best-vitamins-for-skin).

## What the page includes

- **Plate builder:** tap foods to see which of the five vitamins your plate covers
- **The five vitamins:** what each one does in the body and its main food sources
- **Daily amounts table:** recommended amounts and upper limits for adults, from the NIH Office of Dietary Supplements
- **Safety checklist:** stacking supplements, pregnancy, medicine interactions, patch testing and warning signs
- **Where NuBest fits:** which products in the [skin brightening collection](https://www.nubest.com/collections/skin-brightening-supplement) list these vitamins

## Adult reference amounts (ages 19+)

| Vitamin | Recommended daily (men / women) | Upper limit |
|---|---|---|
| Vitamin C | 90 mg / 75 mg | 2,000 mg |
| Vitamin E | 15 mg | 1,000 mg from supplements |
| Vitamin A | 900 / 700 mcg RAE | 3,000 mcg preformed vitamin A |
| Vitamin D | 15 mcg (600 IU), ages 19–70 | 100 mcg (4,000 IU) |
| Niacin (B3) | 16 / 14 mg NE | 35 mg from supplements |

Source: NIH Office of Dietary Supplements consumer fact sheets ([C](https://ods.od.nih.gov/factsheets/VitaminC-Consumer/), [E](https://ods.od.nih.gov/factsheets/VitaminE-Consumer/), [A](https://ods.od.nih.gov/factsheets/VitaminA-Consumer/), [D](https://ods.od.nih.gov/factsheets/VitaminD-Consumer/), [Niacin](https://ods.od.nih.gov/factsheets/Niacin-Consumer/)).

## Deploy with GitHub Pages

1. Create a public repository named `nubest-vitamins-for-skin` under `easyhealthylifestyle`.
2. Upload the four files to the root of the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. The site will be live at `https://easyhealthylifestyle.github.io/nubest-vitamins-for-skin/`.
